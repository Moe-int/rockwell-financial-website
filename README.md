# Rockwell Financial website (concept v2 design)

Static site. Serve the folder (`python3 -m http.server 8765`) or open index.html.
Pages: index, about, services + service-<theme>, how-we-work, insights (+ insights-N), one page per article (<slug>.html), book, contact, privacy.
CSS in css/, fonts in fonts/ (Museo Sans), logo/mark in brand/, hero/family photos in img/, article and section photos in uploads/ (CC0/CC BY stock, credits in brand/image-credits.md of the previous clone backup).
Placeholders: phone (00) 0000 0000, ABN, address, reCAPTCHA; forms post nowhere. Articles and testimonials are rewritten placeholder content.
